# Price Radar — AI Assistant Guidelines (GEMINI.md)

Цей файл містить правила, архітектурні обмеження та контекст проекту для AI-асистентів (Gemini / Antigravity), які працюють над кодовою базою **Price Radar**.

---

## 📌 Про проект
- **Назва:** Price Radar (Офіційна сторінка Telegram-бота моніторингу цін).
- **Призначення:** Лендінг та інтерактивний веб-симулятор для залучення користувачів до бота [@hotline_price_monitor_bot](https://t.me/hotline_price_monitor_bot).
- **Хостинг:** GitHub Pages ([https://ludiscooter.github.io/price-radar/](https://ludiscooter.github.io/price-radar/)) з гілки `main` каталогу `/ (root)`.
- **Основна мова сайту:** Українська (`lang="uk"`).

---

## 🛠️ Стек технологій та жорсткі архітектурні правила

1. **Чистий Vanilla стек (Без збирачів та бекенду):**
   - Тільки чистий **HTML5**, **Vanilla CSS** та **Vanilla JavaScript (ES6+)**.
   - **Заборонено:** додавати важкі фреймворки (React, Vue, Next.js, Vite), Node.js залежності або сторонні бібліотеки збирання, якщо користувач явно цього не попросить.
   - **Заборонено:** додавати TailwindCSS. Усі стилі пишуться виключно у нативному CSS із використанням CSS-змінних.

2. **Структура файлів:**
   - `index.html` — основна семантична розмітка сайту.
   - `styles-v4.css` — дизайн-система, розмітка, Bento-сітка, компоненти та адаптивні медіа-запити.
   - `motion-v4.css` — анімації (`@keyframes`), плавні переходи, ефекти радара та пульсації.
   - `app-v4.js` — клієнтська інтерактивна логіка (радар-симулятор, SVG-графік, калькулятор, чат).
   - `portfolio-case.png` — матеріали для портфоліо та презентації клієнтам.

## 🎨 Дизайн-система та стиль (Dark Cyberpunk Luxury)

- **Колірна палітра (Design Tokens):**
  - Базовий фон: `--bg: #030914;` (Глибокий космос).
  - Картки / Панелі: `--panel: #071327;` (Elevation 1 з border `rgba(255, 255, 255, 0.08)`).
  - Головний акцент: `--cyan: #2ce8ff;` (Неоновий циан, фокусні елементи, градієнти).
  - Вигода та знижки: `--green: #4df18d;` (Смарагдовий зелений).
  - Цілі та рейтинги: `--amber: #fcd34d;`
  - Текст: `--text: #f7fbff;`, приглушений: `--muted: #94a3b8;`.
  - Усі текстові пари мають відповідати стандарту доступності **WCAG 2.1 AAA**.

- **Типографіка:**
  - Заголовки та акценти: **Plus Jakarta Sans** (weights: 600, 700, 800).
  - Тіло та інтерфейс: **Inter** (weights: 400, 500, 600).

- **Доступність (Accessibility):**
  - Завжди зберігати підтримку `@media (prefers-reduced-motion: reduce)` — відключати важкі обертові промені та нескінченні пульсації для чутливих користувачів.

## 🧩 Ключові інтерактивні модулі

1. **Радар-симулятор цін (`#demo`):**
   - Пошуковий рядок + чіпи швидкого вибору (*AirPods Pro 2, PS5 Slim, RTX 4070 Super, MacBook Air M3, Dyson Airwrap*).
   - Анімація сканування магазинів (`.radar-sweep-circle`, `.radar-beam`).
   - Динамічний векторний SVG-графік коливання цін за 30 днів із точками та підказками.

2. **Інтерактивний чат Telegram у Bento (`#features`):**
   - Мокап темної теми Telegram з клікабельними інлайн-кнопками (`🔔 Стежити`, `🎯 Ціль −10%`, `📊 Статистика`).

3. **Калькулятор розумної економії (`#calculator`):**
   - Градієнтний повзунок річного бюджету (10 000 — 200 000 ₴).
   - Перемикачі частоти та знижок із живим підрахунком вигоди.

4. **Інтерактивні категорії (`#categories`):**
   - 8 кнопок категорій з динамічною заміною 3 карток топ-товарів.

5. **Плаваюча кнопка Telegram (`.floating-tg`):**
   - З'являється після скролу > 300px, має пульсуюче неонове кільце та бейдж `1`.
