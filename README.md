# Price Radar

Офіційна сторінка Telegram-бота Price Radar.

Сайт працює без сервера та бази даних. Для публікації через GitHub Pages потрібно завантажити до кореня репозиторію `index.html`, `styles.css`, `motion.css`, `script.js`, `price-radar-avatar.png` і `price-radar-welcome.png`, а потім увімкнути Pages для гілки `main` та каталогу `/ (root)`.
